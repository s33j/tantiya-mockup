# AGENTS.md

## Working rules

- **Don't assume.** If anything is unclear, ask clarifying questions before acting.
- **Be at least 95% confident** before carrying out a task. If you aren't, ask first.
- **No fake data** (mock, seed, or placeholder values) unless I say it's OK.
- **No scope creep.** Do only what was asked. If more work seems needed, write a short proposal and wait for my approval.
- **Never commit to `main`.** Make a feature branch first.
- **Never open a PR to `main`** unless I say it's OK.
- **Delete feature branches after merging.** Once a feature branch is in `main`, delete it locally and on the remote.
- **Keep code DRY.** Reuse existing code; don't duplicate it.
- **No paid plans.** POC uses free tiers only.
- **Conventional Commits.** Use them for commit messages and PR titles.

## After finishing a feature

Review what you built for possible improvements in:

- Data shown
- Performance
- UI
- UX

Write them up as a short proposal for me to approve. Don't implement them without approval.
